WinTool by PcNinja 1.0.0 — first official version.

One tool for Windows Update, Windows Upgrade and Office (replaces WinUpdate Tool, Windows Upgrade Tool and Smart Office Installer).

- One EXE: run it portable or install it (works offline). The MSI is also here for silent installs.
- Windows Update: scan, install, scheduled runs, restart handling. Takes over and removes WinUpdate Tool V1/V2, keeping its schedule.
- Windows Upgrade: in-place upgrade from an ISO or Microsoft's media, with checks before it starts.
- Office: Microsoft 365 / Office LTSC 2024, Visio, Project; install, offline package, remove; default language follows Windows; optional silent install.
- Logs, useful links, self-update (asks before installing).
- English and Hebrew. Spanish is a first translation; corrections are welcome.

Files are not code-signed; check them against SHA256SUMS.txt.
